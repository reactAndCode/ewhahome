# 이화미술공작소 프로젝트 개요 & 인스타그램 미니미 가이드

## 1. 개요
이화미술공작소(EWHA ART) 공식 웹사이트 프로젝트입니다.
최신 트렌드에 맞춰 모바일 친화적인 **인스타그램 프로필 & 피드(Mini-me) 스타일**로 전면 개편되었습니다.

## 2. 주요 UI/UX 기능 및 특징
1. **인스타그램 프로필 헤더**
   - `@ewha_art_min` 공식 계정명 및 블루 인증 마크
   - 시그니처 그라데이션 스토리 링이 감싸는 로고 아바타
   - 게시물(18), 교육경력(16년), 5대 핵심역량 통계 카운터
   - 카카오톡 1:1 상담 바로가기, 네이버 블로그 둘러보기, 링크 복사 기능
2. **스토리 하이라이트 원형 메뉴**
   - 수업안내, 작품갤러리, 원장소개, 교육철학, 공작소공간, 독서융합 원형 아이콘
   - 각 카테고리 클릭 시 관련 게시물만 즉시 필터링
3. **피드 탭 및 듀얼 뷰 모드**
   - ▦ **3열 정방형 피드 그리드**: 인스타그램 특유의 1:1 비율 격자 뷰 (호버 시 하트/댓글 수 표시)
   - 📋 **피드 카드 뷰**: 단일 포스팅 카드 형태로 사진, 상세 본문, 해시태그를 순차 열람
4. **인터랙티브 게시물 모달 (Modal)**
   - 사진 클릭 시 인스타그램 게시물 팝업 오픈
   - 더블 탭(더블 클릭) 시 튀어나오는 하트 애니메이션 및 좋아요 수 실시간 증감
   - 학부모 상담 유도를 위한 카톡 상담 배너 탑재
5. **하단 고정 모바일 앱 독 바 (Bottom Nav Bar)**
   - 홈, 작품 둘러보기, 카톡 상담(+), 피드 모드, 원장 프로필 바로가기

## 3. 파일 구성
- `index.html`: 인스타그램 미니미 메인 웹 애플리케이션
- `docs/overview.md`: 프로젝트 개요 및 기능 문서
- 이미지 자산: 로고 및 학원 사진 20여 종
