# 이화미술공작소 블로그 & 학부모 포털 개발 명세서 (06_dev_blog_spec.md)

---

## 1. 개요 및 개발 목적

본 문서는 **이화미술공작소(Kids Atelier EWHA)** 공식 웹사이트 내에 구축된 **블로그 및 학부모 전용 포털 시스템**의 아키텍처, 디렉토리 구조, UI/UX 디자인 명세, 데이터 모델 및 상세 테스트 시나리오를 기록한 개발 명세서입니다.

- **개발 목표**:
  1. 제공된 시안 이미지(딥 포레스트 그린 카드와 대형 Before & After 비교 및 하단 4개 그리드)의 1:1 시각적 정밀 구현
  2. 관리자(어드민)가 코딩 없이 웹 화면에서 메인 및 4개 카드의 이미지를 실시간으로 교체할 수 있는 기능 제공
  3. 학부모 회원이 로그인했을 때 자신의 아이 활동 사진을 고급스러운 **미술관 액자(Art Frame)** 형식으로 감상하고 기록할 수 있는 마이페이지 제공
  4. 최신 **Next.js (App Router)** 기반 구조에 **Supabase** 클라우드 백엔드를 연동하고, 키 설정 전에도 완벽히 시연 가능한 **스마트 하이브리드 스토어** 탑재

## 5. 핵심 모듈별 상세 기능 명세

### 1) Header & Navigation (`blog/components/Header.tsx`)
- **최상단 테스트 스위처 바**:
  - `학부모 전환`, `어드민 전환` 버튼을 제공하여 비로그인 / 학부모(`parent_minji`) / 관리자(`admin_master`) 상태를 1초 만에 전환 가능.
- **중앙 브랜드 로고**:
  - Kids Atelier EWHA 왕관 엠블럼 SVG 로고와 볼드 타이틀 `이화미술공작소`.
- **6대 핵심 네비게이션 메뉴**:
  1. `아이의 변화` (`#before-after-hero`)
  2. `연령별 수업` (`#programs`)
  3. `수업별 자료실` (`#archive`)
  4. `원장 소개` (`#director`)
  5. `교육철학` (`#philosophy`)
  6. `지난 수업` (`#classes`)
- **조건부 동적 메뉴 활성화**:
  - **학부모 로그인 시**: 핑크 하트 아이콘과 함께 **`🎨 내아이`** 메뉴가 생성되며, 클릭 시 `/mypage`로 이동.
  - **어드민 로그인 시**: 골드 쉴드 아이콘과 함께 **`👑 어드민 설정`** 메뉴가 생성되며, 클릭 시 `/admin`으로 이동.
- **우측 유저 인터페이스**:
  - 비로그인: `로그인`, `회원가입` 버튼 노출 → 클릭 시 팝업 모달 오픈.
  - 로그인 완료: `[사용자 이름] 님` 환영 문구 및 `로그아웃` 버튼 노출.

### 2) 블로그 메인 섹션 (`blog/components/BlogMainHero.tsx`)
- **시안 1:1 완벽 구현**:
  - `38px` 라운딩의 거대한 딥 포레스트 그린 카드 컨테이너.
  - 좌측:
    - 서브 타이틀: `그림, 이렇게 달라집니다!`
    - 메인 타이틀: `BEFORE & AFTER` (Playfair 세리프 대형 폰트)
    - 교육철학: `잘 그리는 법을 가르치기보다 관찰하고, 생각하고, 자기 방식으로 표현하는 힘을 키웁니다.`
    - 알약 버튼: `아이들의 변화 더보기 →`
  - 우측:
    - 2단 분할 듀얼 포토 프레임
    - 좌측: 반투명 세리프 `before` 라벨 + 아이의 스케치 사진
    - 우측: 반투명 세리프 `after` 라벨 + 아이의 컬러 완성작 사진
  - 관리자 로그인 시 우측 상단에 `메인 섹션 편집` 퀵 바로가기 뱃지 노출.

### 3) Before & After 4개 부분 (`blog/components/BeforeAfterGrid.tsx`)
- **4개 미니 비교 카드 그리드**:
  - 1번~4번 카드가 가로 4열로 정렬 (모바일 환경에서는 1~2열 자동 반응형).
  - 각 카드 상단: 좌측 Before 사진(`before` 미니 라벨) + 우측 After 사진(`after` 미니 라벨) 분할 카드.
  - 마우스 호버 시 부드러운 줌 효과 (`scale(1.06)`) 및 카드 부유 인터랙션.
  - 각 카드 하단: 변화 주제 타이틀, 학생 이름, 연령, 선생님의 성장 피드백 문구.
  - 관리자 로그인 시 `4개 카드 이미지 수정하기` 바로가기 링크 제공.

### 4) [신규 추가] 2차 시안 반영: 나머지 5대 메뉴 컴포넌트 (`blog/app/page.tsx`)
제공해주신 2차 디자인 초안을 1:1로 정밀하게 재현하여 메인 블로그 하단에 유기적으로 결합했습니다:

1. **연령별 수업 (5개 카드 그리드)**:
   - `6·7세 유아미술` (놀이로 만나는 첫 미술)
   - `초등 1·2학년` (독서미술과 그림일기)
   - `초등 3·4학년` (관찰하고 표현하는 힘)
   - `초등 5·6학년` (기초디자인으로 넓어지는 시야)
   - `중등 미술` (더 깊은 탐구와 표현)
   - 연한 민트 배경 둥근 카드(`border-radius: 18px`), 클릭 시 상세 교육 과정 팝업 및 활성 토글 연동.

2. **수업별 자료실 (6개 태그 카드 그리드)**:
   - `그리기·드로잉`, `소묘·관찰화`, `수채화·아크릴`, `기초디자인`, `입체·만들기`, `교과융합 미술`
   - 각 영역별 아카이브 자료 카운트 및 포트폴리오 연동 인터랙션 탑재.

3. **원장 소개 & 이화미술의 교육철학 (2단 그리드 박스)**:
   - **좌측: 원장 소개**:
     - 원장님 프로필 사진(`director.jpg`)과 `이화미술공작소 원장 정소담` 타이틀
     - 6대 전문 이력 불릿(이화여대 미술 전공, 디자인·교육학·미술심리치료 전공, 중등 정교사 자격, 미술심리치료사·특수아동지도사·언어발달지도사, 디자이너 경력, 2011 ㅡ 현재 이화미술공작소)
   - **우측: 이화미술의 교육철학 (화이트 2x2 카드 4종)**:
     1. `질문하는 수업`: 스스로 생각하고 표현하는 힘을 키웁니다.
     2. `기초가 만드는 힘`: 관찰·소묘·기초디자인으로 탄탄한 표현력을 만듭니다.
     3. `교과와 세상을 잇는 미술`: 독서, 인문, 과학, 사회와 융합한 깊이 있는 수업을 합니다.
     4. `실패를 두려워하지 않는 마음`: 과정 속에서 성장하는 아이를 응원합니다.

4. **하단 3대 링크 박스 (시안 1:1 완벽 일치)**:
   - `학부모 브리핑 →` : **수업의 가치를 전하는 이야기**
   - `교육 이야기 →` : **미술로 키우는 아이의 내일**
   - `지난 수업 아카이브 →` : **2011년부터 이어온 소중한 기록**
   - 2줄 카드 형태(`bottom-link-card`), 호버 시 우측 화살표 슬라이드 애니메이션 및 팝업 모달 연동.

5. **최하단 푸터 브랜딩 (시안 1:1 완벽 일치)**:
   - 깨끗하고 차분한 라이트 민트 그레이 배경:
   - 상단 볼드 타이틀: `EWHA ART · 이화미술공작소`
   - 하단 영문 슬로건: `Art for a brighter tomorrow · since 2011`

### 4) 어드민 이미지 관리 대시보드 (`blog/app/admin/page.tsx`)
- **기능 1: 메인 섹션 이미지 및 카피 편집**:
  - Before 이미지, After 이미지 각각 파일 업로드(컴퓨터 내 사진) 및 URL 입력 지원.
  - 서브 타이틀, 메인 타이틀, 설명 문구, 버튼 텍스트 실시간 수정.
  - **원클릭 추천 사진 선택기**: 기존 저장소 내의 추천 사진 10종(스케치, 완성작, 조형, 도자기 등)을 원클릭으로 Before/After에 즉시 지정 가능.
- **기능 2: 4개 카드 개별 편집**:
  - 카드 #1 ~ #4 탭 선택 UI.
  - 각 카드의 Before 사진, After 사진, 제목, 학생 이름, 연령, 상세 코멘트 수정.
- **기능 3: 저장 및 동기화**:
  - `변경사항 저장하기` 클릭 시 `saveHeroData()`, `saveCards()`를 통해 영속화.
  - 메인 블로그 화면(`blogHome`)에 새로고침 없이 실시간 반영.
  - 언제든지 원본 시안 상태로 되돌릴 수 있는 `시안 기본값 복원` 버튼 제공.

### 5) 학부모 마이페이지 - 내아이 액자식 앨범 (`blog/app/mypage/page.tsx`)
- **사용자 ID별 데이터 격리**:
  - `user.id`를 기준으로 해당 학부모 계정의 아이 활동 데이터만 필터링하여 렌더링.
- **미술관 원목 액자 프레임 (Museum Art Frame UI)**:
  - `border: 8px solid #3d2b1f`의 중후하고 따뜻한 원목 몰딩 프레임.
  - 내부 캔버스 매트 마감 및 입체 그림자 효과.
  - **황동 명판(Brass Plaque)**: 골드 그라데이션 명판에 작품명, 제작일자, 미술 영역(혼합재료, 동작드로잉, 독서융합 등) 각인 효과.
  - **선생님 피드백 카드**: 아이의 성장 포인트와 표현력을 칭찬하는 코멘트 수록.
  - 사진 클릭 시 화면 가득 크게 감상할 수 있는 고화질 확대 뷰어 모달.
- **새 활동 사진 등록 기능**:
  - 사진 업로드, 작품 제목, 수업일자, 미술 영역 태그, 선생님 코멘트를 입력하여 액자에 즉시 추가.

### 6) Supabase 연동 및 하이브리드 스토어 (`blog/lib/supabase.ts`, `blog/lib/store.ts`)
- **Supabase Client**:
  - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`를 감지하여 유효할 때만 Supabase 인스턴스를 활성화.
- **스마트 Fallback (Local Persistence)**:
  - 환경변수가 입력되지 않은 상태에서도 `localStorage` 기반으로 사용자 로그인, 어드민 이미지 수정, 학부모 활동 액자 저장이 100% 정상 작동.
- **SQL 테이블 스키마 (`blog/supabase_schema.sql`)**:
  - `blog_hero_settings` (메인 섹션 설정)
  - `before_after_cards` (4개 카드 설정)
  - `kid_activities` (학부모 전용 내아이 활동 액자 테이블 및 RLS 보안 정책)

## 6. 테스트 시나리오 (Test Scenarios)

본 시스템의 완벽한 품질과 사용자 경험을 검증하기 위한 6가지 엔드투엔드(E2E) 테스트 시나리오입니다.

### [시나리오 1] 블로그 메인 홈 및 시안 일치도 검증
1. **목적**: 브라우저에서 `http://localhost:3000` (또는 `/blogHome`) 접속 시 첨부 시안과 완벽히 일치하는지 확인.
2. **수행 절차**:
   - 브라우저를 열고 `http://localhost:3000`으로 이동한다.
   - 상단 중앙에 Kids Atelier EWHA 로고와 `이화미술공작소` 타이틀이 표시되는지 확인한다.
   - 네비게이션 메뉴 6개(`아이의 변화`, `연령별 수업`, `수업별 자료실`, `원장 소개`, `교육철학`, `지난 수업`)가 올바르게 배치되었는지 확인한다.
   - 메인 히어로 섹션이 딥 포레스트 그린 카드 컨테이너(`BEFORE & AFTER`)로 렌더링되며, 좌측 문구/알약 버튼과 우측 대형 듀얼 Before/After 사진이 정상 출력되는지 확인한다.
   - 메인 섹션 하단에 4개의 Before/After 미니 카드가 가로 4열로 나란히 표시되는지 확인한다.
3. **기대 결과**: 첨부 시안과 색감, 폰트, 구도, 비율이 100% 일치하며 레이아웃 깨짐이 없음.

### [시나리오 2] 사용자 계정 권한 및 동적 메뉴 활성화 검증
1. **목적**: 비로그인 / 학부모 / 관리자 상태에 따라 네비게이션 메뉴가 동적으로 변화하는지 확인.
2. **수행 절차**:
   - 상단 퀵 스위처 바에서 비로그인 상태를 확인한다.
   - 상단 우측에 `로그인`, `회원가입` 버튼이 노출되는지 확인한다.
   - 상단 바의 `학부모 전환` 버튼을 클릭한다.
   - 계정 상태가 `🎨 학부모(김민지 학부모님)`으로 변경되고, 메뉴바에 **`🎨 내아이`** 메뉴가 생성되는지 확인한다.
   - 상단 바의 `어드민 전환` 버튼을 클릭한다.
   - 계정 상태가 `👑 관리자(총괄 원장선생님)`으로 변경되고, 메뉴바에 **`👑 어드민 설정`** 메뉴가 생성되는지 확인한다.
3. **기대 결과**: 권한에 따라 불필요한 메뉴가 숨겨지고, 권한 보유 시에만 해당 메뉴와 뱃지가 부드럽게 노출됨.

### [시나리오 3] 어드민 메인 섹션 이미지 및 카피 실시간 변경 검증
1. **목적**: 어드민에서 메인 섹션의 Before/After 이미지와 텍스트를 변경했을 때 블로그 홈에 즉시 반영되는지 확인.
2. **수행 절차**:

   - `홈에서 확인하기 →` 링크를 클릭하여 블로그 메인 홈으로 이동한다.
3. **기대 결과**: 블로그 메인 섹션의 서브 타이틀과 우측 After 사진이 관리자가 지정한 사진/문구로 즉시 변경되어 반영됨.

### [시나리오 4] 하단 4개 Before & After 미니 카드 개별 편집 검증

### [시나리오 5] 학부모 마이페이지 내아이 액자식 앨범 및 새 사진 등록 검증

3. **기대 결과**: 키가 없어도 LocalStorage Mock 모드로 완벽하게 테스트 가능하며, 키 입력 시 실제 클라우드 DB로 매끄럽게 확장 가능.

## 8. GitHub Pages 자동 빌드 & 배포 시스템 (방법 1)

본 저장소에는 코드를 `git push`했을 때 GitHub 서버가 자동으로 Next.js 블로그를 빌드하고 메인 홈페이지와 함께 배포해 주는 **GitHub Actions 워크플로우**([`.github/workflows/deploy.yml`](file:///c:/work/mydev/ewhahome/.github/workflows/deploy.yml))가 구축되었습니다.

### 1) 배포 아키텍처 및 경로 매핑
- **`www.ewhaart.co.kr/`**: 루트의 `index.html` (메인 소개 랜딩페이지 및 이미지 에셋 서빙)
- **`www.ewhaart.co.kr/blog/`**: `blog/out` (Next.js 블로그 메인 홈 - Before & After)
- **`www.ewhaart.co.kr/blog/admin`**: 블로그 어드민 대시보드
- **`www.ewhaart.co.kr/blog/mypage`**: 학부모 내아이 액자 앨범
- **`_site/.nojekyll`**: GitHub Pages의 Jekyll 엔진이 Next.js의 `_next/` 번들 폴더를 누락하지 않도록 보호

### 2) 깃허브 저장소 사전 1회 설정 안내
GitHub 저장소 관리자 페이지에서 단 1번만 설정을 확인/변경하시면 됩니다:
1. 저장소 상단 **Settings** 메뉴 클릭
2. 좌측 메뉴의 **Pages** 클릭
3. **Build and deployment > Source** 항목을 **`GitHub Actions`**로 선택
4. 이후 코드를 `git push` 하시면 약 1~2분 후 자동으로 빌드 및 배포가 완료됩니다.
   - 대용량 고화질 원본 사진 저장을 위해 Supabase Storage 버킷(`blog-images`, `kid-frames`)을 생성하고 RLS 정책을 활성화할 것을 권장합니다.
2. **카카오 알림톡 연동**:
   - 선생님이 마이페이지에 새 활동 액자(코멘트)를 등록했을 때 해당 학부모에게 카카오 알림톡이 자동 발송되는 웹훅(Webhook) 연동 가능.
3. **액자 이미지 다운로드 및 인화 신청**:
   - 학부모가 액자 이미지를 고화질 엽서/캔버스 액자 실물로 인쇄 주문할 수 있는 연계 기능 확장 지원.
